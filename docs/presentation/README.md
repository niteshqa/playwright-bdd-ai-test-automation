# Presentation

`automation-benefits.pptx` is a 2-slide deck covering measured benefits and how teams adopt the framework. It is generated by `build-deck.js`.

To regenerate it (pptxgenjs is intentionally not a repo dependency):

```bash
mkdir -p /tmp/deckbuild && cd /tmp/deckbuild && npm init -y && npm i pptxgenjs
NODE_PATH=/tmp/deckbuild/node_modules node <repo>/docs/presentation/build-deck.js
```
